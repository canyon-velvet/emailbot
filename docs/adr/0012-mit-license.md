# MIT license

emailbot should be easy for anyone to use, change and learn from, and OpenBot, which inspired it, is MIT-licensed. So emailbot uses the MIT license: short, permissive and widely understood.

## Consequences

- Anyone may reuse the code, including in closed-source products.
- Contributions come in under the same license they go out under.
- Unlike Apache-2.0, MIT has no explicit patent grant.
